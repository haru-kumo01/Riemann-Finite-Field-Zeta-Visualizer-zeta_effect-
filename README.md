# Riemann & Finite Field Zeta Visualizer (`zeta_effect`)

## はじめに (About)

数学もプログラミングも素人同然の作者が、話題の「リーマン予想」に興味を持ち、Gemini（AI）と対話しながら「リーマン予想の世界を擬似的に映像と音で体験できるツール」を作ってみました。

作っている本人も、数式の詳しい中身やコードの細かい仕組みは正直よくわかっていない仕様です。  
それでも、数学者が頭の中で思い描いているような世界を擬似的に覗き見ることができる、面白いツールに仕上がったと思います。

おそらく専門家や熟練エンジニアの方には不要なツールかもしれませんが、数学やプログラミングの知識がない方が気楽にこのエフェクト風アニメーションを眺めて、宇宙や数学の世界へ想像を膨らませて楽しんでいただければ幸いです。


## ツールの説明
リーマンゼータ関数 ζ(s) と有限体ゼータ関数（合同ゼータ関数）の数式を「見えない力場（フォースフィールド）」に見立て、20,000個の光の粒子とリアルタイム音響シンセサイザーで可視化・可聴化するインタラクティブ・ビジュアライザーです。

Rust・Bevy 0.20・rodio を使用し、画像や音声などの外部アセットを一切使わず、**純粋な数式とコードのみ**から宇宙の星雲・台風のような渦・万華鏡（マンダラ）の映像と和音をリアルタイム生成しています。

## 主な特徴 (Features)

1. **2つの宇宙モードのリアルタイム切り替え（抽象のレンズ）**
   * **1. RIEMANN ZETA（無限の連続宇宙）**: 臨界線 Re(s) = 1/2 上の非自明な零点（台風の目）に向かって、20,000個の光の粒子が星雲や渦のように吸い込まれていく宇宙モデル。
   * **2. FINITE FIELD（閉じた箱庭・万華鏡宇宙）**: 臨界真円上に等間隔に並んだ零点（4〜32個まで変更可能）の周りを、粒子が消えることなく永遠に循環し続ける対称幾何学（マンダラ）モデル。
2. **2D（縦の帯） ⇔ 3-Ring（円盤・同心円）モーフィング**
   * 縦に伸びる帯状の空間を、ボタンひとつで真上から見下ろす3重の光のリングへと滑らかに変形できます。
3. **BIG BANG!（特異点からの再膨張演出）**
   * 零点に収束して静まり返った空間の中心から、ワンクリックで粒子を全宇宙へ弾き飛ばし、再び銀河や渦が形成されるプロセスを何度でも観測できます。
4. **無制限タイムライン＆シークバー（逆再生・速度微調整対応）**
   * チェックポイント方式により、時間の早送り・巻き戻し（逆再生）・一時停止・`0.05x` 刻みの速度調整・1時間以上の長時間観測が可能です。
5. **カラーホイール（色サークル）＆虹色スペクトルモード**
   * 画面右上の色サークルをマウスでドラッグして360度すべての色相・彩度をリアルタイム変更可能。中央クリックで七色に輝く `Rainbow` モードに切り替わります。
6. **3種類のリアルタイム音響シンセサイザー（`rodio` 波形生成）**
   * **1. Chord（零点ハーモニー）**: 非自明な零点の数値比率を可聴域の周波数に変換し、粒子の収束度に応じて和音が響きます。
   * **2. Sparkle（粒子のきらめき）**: 結晶化する粒子の高音ベル・スパークル音。
   * **3. Drone（深宇宙アンビエント）**: 重厚な低音ドローンと倍音のうねり。

## 操作方法 (Controls)

### 画面UIボタン
* **上部中央バナー**: `RIEMANN ZETA` ⇔ `FINITE FIELD` の宇宙モード切り替え
* **右上 `HUD: ON / OFF`**: UIとシークバーをすべて隠す全画面観賞モード
* **右上 色サークル**: ドラッグで色相・彩度変更 ／ 中央クリックで `Rainbow` モード切替
* **下部シークバー**: マウスドラッグで任意の時刻へ瞬時に移動
* **下部コントロールバー**:
  * `|| STOP / > PLAY`: 再生・一時停止
  * `REV`: 通常再生 ⇔ 逆再生（巻き戻し）
  * `Spd -0.05 / +0.05`: 再生速度の数値微調整（`0.05x` 〜 `10.0x`）
  * `Max -1m / +1m`: シークバーの最大スケール時間を1分単位で延長・短縮
  * `Im -1 / +1`: 観測高度 Im(s)（有限体モードでは回転角）の移動
  * `View: 2D / 3-Ring`: 2D縦帯 ⇔ 3重リングのモーフィング変形
  * `Zeros`: 有限体モードの零点数切り替え（`4, 6, 8, 12, 16, 24, 32`）
  * `BIG BANG!`: 特異点からの大爆発と再収束のトリガー
  * `Hue / Color`: プリセットカラー＆虹色モード切り替え
  * `Audio`: 音響モード切替（`OFF` → `1.Chord` → `2.Sparkle` → `3.Drone`）
  * `Reset`: 初期状態へリセット

### キーボード＆マウスショートカット

| キー / 操作 | 機能 |
| :--- | :--- |
| **`U`** | 宇宙モード切替（Riemann Zeta ⇔ Finite Field） |
| **`G`** | **BIG BANG!** 発生 |
| **`Z`** | 有限体モードの零点数変更 |
| **`Tab`** | 2D表示 ⇔ 3-Ring（3重リング）表示の変形 |
| **`Space`** | 再生 / 一時停止 |
| **`B`** | 逆再生（リバース）ON / OFF |
| **`<` (`,`) / `>` (`.`)** | 時間の巻き戻し / 早送り |
| **`W` `A` `S` `D` / 矢印キー** | カメラ移動（高さ・実部の探索） |
| **マウスホイール** | ズームイン / ズームアウト |
| **`1` / `2`（または `[` / `]`）** | 粒子の発光輝度（明るさ）調整 |
| **`C`** | プリセットカラー / 虹色モード切替 |
| **`M`** | 音響シンセサイザーのモード切替 |
| **`H`** | HUD（UI表示）の ON / OFF |
| **`R`** | パラメータのリセット |

## ビルドと実行方法 (Build & Run)

Rust（`cargo`）がインストールされた環境で、以下のコマンドを実行します。

```bash
cargo run --release
```

配布用の単体実行ファイル（Windowsでは黒いコンソール画面なしで起動）を作成する場合は以下を実行します：

```bash
cargo build --release
# target/release/zeta_effect.exe が生成されます
```

## プロジェクト構成 (Architecture)

```text
src/
├── main.rs          # アプリケーションの起動とシステム登録
├── state.rs         # 設定定数・SimState・カラーサークル（HSV）定義
├── math.rs          # リーマンゼータ関数および有限体ゼータ関数の複素数計算
├── sim.rs           # パーティクル物理演算・ビッグバン衝撃波・チェックポイント管理
├── audio.rs         # rodio による3種類のリアルタイム波形シンセサイザー
├── input_ui.rs      # ボタン・色サークル・シークバーのマウス判定
├── input_keys.rs    # キーボード・ホイール入力と時間進行制御
├── ui_build.rs      # Bevy UI レイアウトとマーカーコンポーネントの構築
├── ui_sync.rs       # UIテキスト・HUD表示状態のリアルタイム同期
└── render_space.rs  # Gizmos による2D/3-Ring宇宙・万華鏡・色サークルの描画
```
